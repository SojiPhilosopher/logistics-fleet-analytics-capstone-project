# Logistics Fleet Analytics Capstone Project

## Project Overview

This Power BI capstone project analyzes logistics and fleet operations using interactive dashboards and business intelligence techniques. The project focuses on operational performance, trip analysis, fuel consumption, and fleet efficiency.

## Tools Used

* Power BI
* Power Query
* DAX
* Data Modeling
* GitHub

## Dashboard Pages

### 1. Executive Overview

Provides a high-level summary of:

* Total trips
* Fuel cost
* Average MPG
* Delivery performance
* Operational KPIs

### 2. Operations & Trip Analysis

Analyzes:

* Trip volume trends
* Driver distance performance
* On-time vs late deliveries
* Route load performance
* Average trip duration

### 3. Fuel & Efficiency Analysis

Focuses on:

* Fuel consumption trends
* Fuel cost analysis
* Driver fuel efficiency
* Average MPG performance
* Distance vs fuel cost analysis

## Key Insights

* August 2022 recorded the highest trip volume.
* Thomas Gonzalez covered the highest total distance.
* Barbara Moore recorded the highest average MPG.
* Fuel costs increased significantly during high operational periods.
